API key

This deployment requires a key. It is kept in this browser's local storage and sent as a bearer token — treat it like a password and use a private browser profile on a shared machine.

Sign in

Nobody needs to sign in to use this site. Signing in is for the people who look after it: it does what the admin key does, and puts your name on what you approve and send. A link to sign in is emailed to you.
